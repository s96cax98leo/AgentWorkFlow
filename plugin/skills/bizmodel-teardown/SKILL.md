# Business Model Teardown — 商業模式拆解

## 方法：從公開定價頁反推整個獲利引擎

### 1. 定價階梯的完整擷取（做到底，別只抄首頁）
必須分別記錄，混為一談是最常見的錯誤：
| 欄位 | 說明 |
|---|---|
| 方案名 | |
| **促銷價** | 首頁大字、通常綁最長期約 |
| **原價 / 續約價** | 常藏在小字、結帳頁或條款 |
| **綁約期** | 1/12/24/48 月，價差可達 3-5 倍 |
| 折扣幅度 | (原價-促銷價)/原價 |
| 資源配額 | 網站數、儲存、頻寬、信箱、CPU/RAM 或等效配額 |
| 贈品 | 免費網域（首年）、SSL、遷移、CDN、信箱 |
| 退款保證 | 天數與排除項（網域費通常不退） |

**續約溢價 = 這類生意的真正毛利來源。** 首年可能是虧本或打平的獲客成本，第二年起才是利潤。務必把「首年總支出 vs 次年總支出」算成一張表。

### 2. 錨定與行為設計（逐項辨識並取證）
- 誘餌方案（deliberately worse middle tier）
- 「最受歡迎」標籤放在哪一階 → 目標推銷對象
- 預設勾選的最長期約 / 預設加購項
- 倒數計時、庫存稀缺、劃線價 → 緊迫感手法
- 結帳漏斗中的加購牆（隱私保護、備份、安全套件、專屬 IP、優先客服）
- 升級提示的出現時機（配額用盡？流量尖峰？）

判定合規性時，區分「積極行銷」與「暗黑模式」（誤導性劃線價、難以取消、預設加購未明示）。用中性語言記錄事實，讓讀者自行判斷。

### 3. 營收組合拆解
估算各條營收線佔比與毛利率差異：
- 主機方案（訂閱，毛利中等，受硬體成本牽制）
- **網域註冊與續約**（低毛利進場、高續約黏著，是流量入口）
- 加值服務（SSL、備份、隱私、信箱、安全）→ **高毛利，幾乎純軟體**
- 網站建置工具 / AI 工具（提高 ARPU 與轉換率的槓桿）
- 企業／VPS／雲主機（高 ARPU，往上打市場）
- 聯盟行銷與經銷（同時是成本也是通路）

### 4. 單位經濟建模
```
ARPU        = 年營收 / 平均活躍帳號
CAC         = 行銷支出 / 新增付費客戶（聯盟佣金常是主要成分）
Gross margin= (營收 - 主機成本 - 網域批發成本 - 金流費) / 營收
Churn       = 續約率的補數；主機業關鍵在「首年→次年」的斷崖
LTV         = ARPU × 毛利率 / churn
Payback     = CAC / (ARPU × 毛利率 / 12)  月數
```
所有輸入沒有官方數字時，用產業區間並做**三情境**（保守／基準／樂觀）。

### 5. 獲客引擎
- SEO 內容規模（教學文、比較文）與排名 → 自然流量護城河
- 聯盟計畫佣金結構（每單固定額 vs 分潤；額度反推可容忍的 CAC）
- 評測站／比較站的付費置入
- 品牌組合策略（同集團多品牌覆蓋不同價格帶與市場，避免自相殘殺）

### 6. 護城河與脆弱點
護城河：轉換成本（遷移麻煩）、網域鎖定、品牌組合規模經濟、自建基礎設施的成本優勢、SEO 資產。
脆弱點：續約價衝突導致的口碑風險、超大型雲的降價、AI 建站工具重塑入門市場、法規（GDPR、消費者保護對自動續約的規範）。

### 7. 競品定位
把目標與 3-5 個對手放進同一張表：入門促銷價 vs 續約價 vs 資源配額 vs 目標客層。
點出目標選擇的**戰略位置**（極致低價入門？中階均衡？企業級？）與其必然的取捨。

## 輸出格式
寫入 `artifacts/<target>/business-model.md`：
1. 一句話商業模式摘要
2. 完整定價矩陣（促銷 vs 續約，含綁約期）
3. **首年 vs 次年支出對照表**（本報告最有殺傷力的一張）
4. 營收線拆解與毛利推估
5. 單位經濟模型（三情境 + 假設表）
6. 獲客引擎與轉換設計清單（附截圖或原文引用）
7. 護城河 / 脆弱點
8. 競品定位表

## 鐵律
價格必須註明**擷取日期、幣別、地區**——這類站會依 IP 顯示不同價格與貨幣。
描述行銷手法用可驗證的中性事實（「預設選取 48 個月方案」），不要用情緒化指控。
