## 2. 決定：帶哪些、怎麼帶
- 載入方式：【CDN／本機託管】。展示環境網路不可靠時建議本機託管。
- 每個字族：檔案來源、字重範圍、是否做子集、放置路徑、LICENSE 放字檔旁。
- 不需要的字族（例如頁面語言用不到的 CJK 字體）不帶，並寫理由。
