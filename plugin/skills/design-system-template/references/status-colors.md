# 狀態 → 顏色、語意角色色（全站一致；骨架）

出處：DS:【行】。狀態值照原文大小寫，「—」＝原文該格空白。

## 1. 狀態 → 顏色對照（照原文）

| 領域 | neutral | info | warning | success | error |
|---|---|---|---|---|---|
| 【領域 A，例如 任務執行】 | 【created、cancelled】 | 【running】 | 【waiting】 | 【completed】 | 【failed】 |
| 【領域 B】 | | | | | |

- 一律用徽章呈現，**顏色＋文字並用**，不單靠顏色。
- 原文對應看起來不直覺也照原文，不自行調整。
- 產品的狀態若不在上表，DS 文件未定義對應。建議做法：依語意對到最接近的一欄並在 PR 說明列出，有疑義就列給決策者（進行中→info、等人處理→warning、完成→success、失敗／拒絕→error、尚未開始／作廢→neutral），不新增顏色。

## 2. 徽章各 tone 用的色階

| tone | 底 | ring | 字 |
|---|---|---|---|
| primary | 【50 階】 | 【200 階】 | 【600 階】 |
| success | | | 【若 600 對比不足改 700，註明】 |
| info | | | |
| warning | | | |
| error | | | |
| neutral | | | |

每個字色／底色組合都要算對比（WCAG AA 4.5:1），不足的在這裡註明改用哪一階。
