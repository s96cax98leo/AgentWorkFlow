# 品牌標誌（骨架）

## 1. 規格（DS:【行】）
- 圖形：【填空：形狀、組成、viewBox】
- 色值：【填空；全部加進 allowlist.txt 並註明出處】
- 最小尺寸、留白、不可變形規則：【填空】

## 2. 元件版（【產品元件路徑】）
- 漸層或 clipPath 的 id 用唯一 id（例如 React `useId()`），避免同頁多個標誌互相參照。
- 不要讓標誌參照被 `display:none` 隱藏的 defs（窄螢幕會畫不出來）。
- 標誌當連結時要有可讀名稱（`aria-label` 或可見文字），SVG 本身 `aria-hidden`。
